## ✨ 主な特徴
- **3ヶ国語対応** (英語/日本語/ロシア語)
- リアルタイム天気データ (Open-Meteo/OpenUV/Moment Timezone/GeoNames APIを使い)
- 時間帯に連動したアニメーション
- モバイルから4Kディスプレイまで完全対応

## 🌟 技術的ハイライト
- 国際化(i18next)の実装経験
- タイムゾーン処理の難題解決
- CSSアニメーションの最適化
